# SongsCRUD for Android

A lightweight Android shell for a personal SongsCRUD music server. The existing web app runs inside Android WebView, with native voice input, file selection and Back controls.

## Download

Get the signed APK from [Releases](https://github.com/anoopsimon/songscrud-android/releases/latest). Requires Android 8.0 or newer.

Connect to the configured private network, install the APK, and open SongsCRUD. The APK is configured for the owner's server; downloading it does not grant access to that server. This is not a standalone/offline music service.
